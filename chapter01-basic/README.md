# Chapter 01 - Java 基础

这一章记录 Java 入门阶段的练习代码，内容从第一个程序开始，一直到基础运算符。

## 包结构

```text
chapter01-basic
└── src
    └── com
        └── hanqi
            └── basic
                ├── demo
                └── lab
```

## demo 练习

| 文件 | 学习内容 |
| --- | --- |
| `HelloWorldDemo.java` | 第一个 Java 程序，学习 `main` 方法和控制台输出 |
| `CommentDemo.java` | 单行注释、多行注释、文档注释 |
| `LiteralDemo.java` | 整数、小数、字符、字符串、布尔值等字面量 |
| `VariableDemo.java` | 变量的定义、赋值、修改和常量 |
| `DataTypeDemo.java` | Java 基本数据类型和字符串 |
| `TypeConversionDemo.java` | 自动类型转换和强制类型转换 |
| `InputDemo.java` | 使用 `Scanner` 接收键盘输入 |
| `ArithmeticDemo.java` | 算术运算符：`+`、`-`、`*`、`/`、`%` |
| `AssignmentDemo.java` | 赋值运算符和复合赋值运算符 |
| `IncrementDemo.java` | 自增、自减，以及前置和后置区别 |
| `ComparisonDemo.java` | 比较运算符，结果是 `boolean` |
| `LogicalDemo.java` | 逻辑运算符：`&&`、`||`、`!` |
| `TernaryDemo.java` | 三元运算符 |

## lab 练习

| 文件 | 学习内容 |
| --- | --- |
| `BMI.java` | 综合练习：变量、键盘输入、计算、输出结果 |

## 如何运行

1. 用 IntelliJ IDEA 打开 `Java-Learning` 项目。
2. 展开 `chapter01-basic/src/com/hanqi/basic`。
3. 打开 `demo` 或 `lab` 里面的 Java 文件。
4. 点击 `main` 方法左边的绿色运行按钮。

每个练习类都可以单独运行。
