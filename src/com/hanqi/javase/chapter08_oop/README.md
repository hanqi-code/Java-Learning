# Chapter 08 面向对象基础

本章学习 Java 面向对象基础，包括类、对象、构造方法、this、private 封装、JavaBean、对象数组等内容。

## 学习内容

- 类和对象
- 多个对象
- 成员方法
- 对象作为方法参数
- 构造方法
- this
- private
- setter / getter
- 标准 JavaBean
- 对象数组
- 对象数组统计

## 核心理解

- 类定义对象的数据和行为
- new 用来创建对象
- 对象变量保存对象地址
- 多个变量可以指向同一个对象
- this 表示当前对象
- private 用来保护成员变量
- setter 用来修改数据
- getter 用来读取数据
- 对象数组中保存的是多个对象地址
